# Airlines AI Assistant
This Python code creates an AI assistant for an airline. When the assistant is called to tell the ticket price of a destination, it uses a tool to retrieve ticket price information from sqlite database and displays the price information along with audio message and an image generated based on tourist spots and everything unique about that city. If the destination is not covered by that airlines, AI assistant politely says so. OpenAI is used as the LLM here and you need your own OpenAI API key to run this code.
